IncomingCallData

data class IncomingCallData(val callId: String, val title: String, val body: String = DEFAULT_BODY, val sender: Caller? = null, val callerId: String? = null, val receiverId: String? = null, val extraData: Map<String, String> = emptyMap())

The call description sent as the data object when triggering an incoming-call push.

This is the send-side counterpart of IncomingCallPayload: what a device receives and parses is exactly what the caller built here. The fields the receiving SDK requires to ring (type, callId, callTimestamp, body, title) are guaranteed — type and callTimestamp are supplied by the SDK, the rest are constructor parameters — so an unringable payload cannot be constructed.

Throws

IllegalArgumentException

if callId or title is blank, or extraData uses a reserved key.
