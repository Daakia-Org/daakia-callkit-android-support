DaakiaCallKit

object DaakiaCallKit

Entry point of the Daakia CallKit SDK.

Initialize once from your Application.onCreate, before using any other API:

DaakiaCallKit.initialize(
    context = this,
    config = DaakiaCallKitConfig(baseUrl = "https://…", secret = "…"),
)
Content copied to clipboard

The API falls into five groups:

  • Receiving calls — handleRemoteMessage (or ai.daakia.callkit.push.DaakiaMessagingService) turns a Daakia push into a ringing incoming call.

  • Placing calls — registerDevice, getRegisteredDevice, startCallByUsername, startCallByToken. These are suspend; call them from your own scope.

  • Reporting call lifecycle — sendCallEvent while the app runs, plus configureCallEventFallback for the killed-state path.

  • Cancelling a ringing call — endCall, for when the caller hangs up first.

  • Observing — callEvents and consumeLaunchEvent.

  • Permissions — canUseFullScreenIntent and openFullScreenIntentSettings.

Whether the app may use full-screen intents, i.e. whether the incoming-call screen can appear over the lock screen. Always true below Android 14; on Android 14+ the user can revoke it, in which case the call shows as a heads-up notification only — check this and offer openFullScreenIntentSettings from your app's settings.
