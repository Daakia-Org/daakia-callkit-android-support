IncomingCallUi

object IncomingCallUi

Contract between the core call pipeline and a full-screen incoming-call Activity.

callkit-ui-compose and callkit-ui-views build on this to provide ready-made call screens; a host app with its own call UI uses it directly: register the Activity with registerActivity, read the call from the launch intent with launchPayload, and report the user's choice with acceptCall / declineCall. While ringing, keep an onCallClosed subscription and finish the Activity when the ringing call ends elsewhere (timeout, remote end, accept from the notification).
