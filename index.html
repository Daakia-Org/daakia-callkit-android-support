Daakia CallKit — Android SDK

Native Android SDK for Daakia-backed incoming call signaling.

Published to Maven Central as ai.daakia:callkit-core, ai.daakia:callkit-ui-compose, and ai.daakia:callkit-ui-views. Start with Getting started, or run the sample app.

Guides

  • Getting started — from an empty app to a ringing call in about 20 minutes: install, Firebase, manifest, receiving and placing calls.
  • Handling call events — the complete guide to ACCEPTED vs the event flow, the replay buffer, deduplication, and lock-screen handling. Read this if the event model felt confusing.
  • The incoming-call screen — the preset UI modules, the three styles, theming, and building your own call Activity.
  • Choosing the right API — which API to use when, for the pairs that look redundant.
  • Troubleshooting — diagnosing calls that don't ring, layer by layer, including OEM battery managers.
  • Permissions — every permission the SDK declares and why.

Onboarding

  • Client onboarding checklist — what a client provides before integration starts, and what they get back. Skip if onboarding is done.
